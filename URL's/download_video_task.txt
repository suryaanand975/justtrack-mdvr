================ Request Example =================

http://119.23.207.22/StandardApiAction_addDownloadTask.action?jsession=cf6b70a3-c82b-4392-8ab6-bbddce336222&did=500000&fbtm=2015-12-25 00:00:00&fetm=2015-12-30 23:59:59&sbtm=2015-12-25 00:00:00&setm=2015-12-30 23:59:59&lab=downloadExample&fph=H20121123-112931P3A1P0.avi&vtp=1&len=5000&chn=1&dtp=1


================ Explanation =================

- jsession : Session token from Login API (mandatory)
- did      : Device ID
- fbtm     : Requested download start time
- fetm     : Requested download end time
- sbtm     : Source file start time
- setm     : Source file end time
- lab      : Optional label for download task
- fph      : File path/name from query video API
- vtp      : Record type (0=normal,1=alarm)
- len      : File size in bytes
- chn      : Channel number
- dtp      : Download type
             1 → Full download
             2 → Segment download


================ Notes ==============================================

- Segment download is supported for all devices
- Full download supported only for specific device types (16,17,20,22)
- If video has multiple channels → only segment download allowed
- fbtm/fetm must be within sbtm/setm range
- File path (fph) should be taken from Query Video API response
- This API creates a download task, not direct file download
