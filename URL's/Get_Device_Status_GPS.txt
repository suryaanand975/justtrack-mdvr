================ Interface Description : Get Device Status (GPS) =================

API URL : http://119.23.207.22/StandardApiAction_getDeviceStatus.action?
Method  : GET / POST

---------------------------------------------------------------
Parameter       Value               Description
---------------------------------------------------------------
jsession        <session_id>        Session ID from login API (Required)
devIdno         500000              Device ID (comma separated for multiple)
vehiIdno        <optional>          Vehicle plate number (if devIdno empty)
geoaddress      1                   Enable geo location analysis (1 = yes)
driver          1                   Get driver info (1 = yes)
toMap           1                   Map conversion (1=Google, 2=Baidu)
language        zh                  Language (zh = Chinese, en = English)
---------------------------------------------------------------


================ Request Example =================

http://119.23.207.22/StandardApiAction_getDeviceStatus.action?jsession=cf6b70a3-c82b-4392-8ab6-bbddce336222&devIdno=500000&toMap=1&language=zh


================ Success Response =================

{
  "result": 0,
  "status": [
    {
      "id": "500000",
      "vid": null,
      "lng": 113921858,
      "lat": 22568745,
      "sp": 520,
      "ol": 0,
      "gt": "2015-12-14 18:54:58.0",
      "mlng": "113.926720",
      "mlat": "22.565703",
      "ps": "113.926720,22.565703"
    }
  ]
}

Explanation:
- result : 0 → Request successful
- id     : Device ID
- vid    : Vehicle number (null if queried by device)
- lng/lat: Raw GPS coordinates (divide by 1,000,000)
- sp     : Speed (divide by 10 → km/h)
- ol     : Online status (1 = online, 0 = offline)
- gt     : GPS upload time
- mlng/mlat : Converted map coordinates
- ps     : Geo location (longitude, latitude)


================ Notes ======================================

- jsession must be obtained from Login API
- devIdno and vehiIdno support multiple values (comma separated)
- If devIdno is empty, vehiIdno will be used
- Speed and fuel values require conversion before use
