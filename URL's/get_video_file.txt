================ Interface Description : Query Video =================

API URL : http://119.23.207.22/StandardApiAction_getVideoFileInfo.action?
Method  : GET / POST

---------------------------------------------------------------
Parameter       Value               Description
---------------------------------------------------------------
DevIDNO         500000              Device ID / Plate Number (Required)
LOC             2                   Search location (1=device, 2=server, 4=download server)
CHN             0                   Channel (0=channel1, 1=channel2, -1=all)
YEAR            2014                Year
MON             12                  Month
DAY             10                  Day
RECTYPE         -1                  Record type (0=normal,1=alarm,-1=all)
FILEATTR        2                   File type (1=image,2=video)
BEG             0                   Start time (seconds: 0–86399)
END             86399               End time (seconds: 0–86399)
ARM1            0                   Alarm identification 1
ARM2            0                   Alarm identification 2
RES             0                   Media type (0=audio+video,1=audio,2=video)
STREAM          0                   Stream type (0=main,1=sub,-1=both)
STORE           0                   Storage type
LABEL           <optional>          Label
jsession        <session_id>        Session ID from login API
---------------------------------------------------------------


================ Request Example =================

http://119.23.207.22/StandardApiAction_getVideoFileInfo.action?DevIDNO=500000&LOC=2&CHN=0&YEAR=2014&MON=12&DAY=10&RECTYPE=-1&FILEATTR=2&BEG=0&END=86399&ARM1=0&ARM2=0&RES=0&STREAM=0&STORE=0&jsession=649b7687-6792-41a2-b9be-7806f2a0d3fa


================ Success Response =================

{
  "result": 0,
  "cmsserver": 1,
  "files": [
    {
      "devIdno": "500000",
      "chn": 1,
      "beg": 31044,
      "end": 32842,
      "year": 10,
      "mon": 1,
      "day": 11,
      "file": "H20100628-083724P2N2P0.264",
      "len": 23211837,
      "loc": 1,
      "type": 0,
      "recing": 0,
      "PlaybackUrl": "http://localhost:6604/...",
      "PlaybackUrlWs": "ws://localhost:6604/..."
    }
  ]
}


Explanation:
- result        : 0 → Success
- devIdno       : Device ID
- chn           : Channel number
- beg/end       : Start/End time (seconds)
- year/mon/day  : Date (year + 2000)
- file          : File name
- len           : File size (bytes)
- loc           : File location (1=device,2=server,4=download)
- type          : Record type (0=normal,1=alarm)
- recing        : Recording status (0=no,1=yes)
- PlaybackUrl   : HTTP playback URL
- PlaybackUrlWs : WebSocket playback URL (preferred)

Explanation:
- res      : Media type (0=audio+video,1=audio,2=video)
- store    : Storage type
- stream   : Stream type (-1=both,0=main,1=sub)


================ Notes =======================================

- jsession must be obtained from Login API
- Supports cross-day video queries
- BEG and END are in seconds (0–86399)
- PlaybackUrlWs is preferred over PlaybackUrl
- Multiple channels supported using CHN or chnMask
- Video files may span across multiple days
